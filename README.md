# Overtone Sierra Leone website

Plain HTML, CSS and vanilla JavaScript. No frameworks, no tracking, no secrets.

## Structure
- `*.html`: pages. **They are generated by `build.py`** so the header, footer and SEO tags stay identical. Edit content in `build.py`, then run `python3 build.py`. (You can also edit the HTML directly if you stop using the script.)
- `style.css`: design tokens (colours, fonts) are at the top.
- `main.js`: menu, back-to-top, gallery filter and lightbox, form validation.
- ``: `overtone-logo.png` (logo, trimmed of surrounding whitespace only), `founder-khadison-duwai.jpg`, `overflow26-flyer.jpg`.
- `robots.txt`, `sitemap.xml`: templates.

## Run locally
`cd overtone-sl && python3 -m http.server 8000`, then open http://localhost:8000

## Go live
1. In `build.py`, change `SITE` to your real domain, run `python3 build.py`. This updates canonical URLs, Open Graph URLs, JSON-LD, `sitemap.xml` and `robots.txt`.
2. Upload the folder to any static host (Netlify, Cloudflare Pages, GitHub Pages, cPanel). Set HTTPS.
3. Create a 1200 x 630 share image and point `og:image` at it (optional).

## Make the forms send messages
Until you do this, forms validate but tell visitors **"not sent"** and show your phone numbers. They never fake success.
Use a form service (Formspree, Getform, Netlify Forms, or your own backend). Put its endpoint URL in the `data-endpoint` attribute of each `<form>` (in `build.py`, `form()` calls pass `endpoint=`). Never put private API keys in the front end.

## Add content
- Program: copy an `article.card` in `programs.html`. Initiative: copy a `card todo`. Event: copy `article.event`; move it under Past events afterwards.
- Gallery photo: copy the `figure.g-item`, set `data-cat` (events, leadership, community, creative), image, alt text and caption.
- Testimonials: the section on the homepage is `hidden`. Add real, permitted quotes, then remove `hidden`.
